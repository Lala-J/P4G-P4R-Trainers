# P4R trainer (Persona 4 remake)

Nothing here yet. This folder will hold the trainer for the Persona 4 remake once the game
is released and can be studied. The plan is to offer the same feature set as the
[P4G trainer](../P4G/), rebuilt for the new engine. Very little of the P4G code is
expected to carry over, because the two games share a story but not an engine.
